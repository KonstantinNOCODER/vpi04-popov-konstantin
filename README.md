# VPi04 — VK-бот «Каталог услуг no-code студии»

Бот для сообщества VK: главное меню, каталог услуг с описаниями и ценами, прайс-лист и
подсказка, как связаться с менеджером. Работает через **Group LongPoll API** на
[vkbottle](https://github.com/vkbottle/vkbottle) 4.11.0.

## Возможности

- Постоянная клавиатура VK: «Услуги», «Прайс-лист», «Связаться с менеджером».
- Карточка каждой услуги: описание и стоимость «от …».
- Кнопки «⬅ К услугам» и «⬅ Главное меню».
- Маршрутизация по `payload` кнопок; текстовые синонимы («меню», «услуги», «прайс»…).
- Неизвестный/битый payload и произвольный текст → подсказка и главное меню.
- Бот отвечает только на входящие личные сообщения пользователей (игнорирует `out=1`
  и сообщения от имени групп).
- Каталог в `data/services.json` валидируется при запуске; пустой каталог обрабатывается.

## Структура

```
bot.py               точка входа (bot.run())
app/config.py        загрузка VK_GROUP_TOKEN из .env
app/catalog.py       загрузка, валидация и форматирование каталога
app/router.py        payload/текст -> ответ (без зависимостей от vkbottle)
app/keyboards.py     клавиатуры VK
app/handlers.py      обработчик vkbottle и фильтр входящих сообщений
app/texts.py         тексты и подписи кнопок
data/services.json   каталог услуг
tests/               unittest-тесты каталога и маршрутизации
```

## Установка (Windows, PowerShell)

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и укажите токен сообщества в `VK_GROUP_TOKEN`. Файл `.env` исключён из git.

## Настройки сообщества VK

Управление → Работа с API:
- ключ доступа с правами на сообщения сообщества;
- Long Poll API включён, в типах событий отмечено «Входящее сообщение» (`message_new`).

Управление → Сообщения: сообщения включены; «Настройки для бота» → «Возможности ботов» включены
(нужно для клавиатур).

> Если бот из VPi03 работает с тем же сообществом, остановите его — иначе оба будут отвечать.

## Запуск

```powershell
python bot.py
```

Остановка — `Ctrl+C`.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты не требуют токена, сети и vkbottle.

## Изменение каталога

Отредактируйте `data/services.json` (UTF-8). Поля услуги:

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | строка | `a-z`, `0-9`, `_`, до 32 символов, уникален |
| `title` | строка | до 40 символов (лимит кнопки VK) |
| `price_from` | целое число | ≥ 0 |
| `currency` | строка | например, `₽` |
| `description` | строка | непустая |

После изменения перезапустите бота.
