# Сравнительный анализ AI-инструментов

## Кейс №1. Исправление существующего проекта

**Задача:** Исправить ошибки, улучшить архитектуру и провести рефакторинг существующего интернет-магазина на Python с несколькими тысячами строк кода.

**Выбор эксперта:** Claude Code.

**Обоснование:** При работе с большим существующим проектом важно сначала разобраться в структуре кода и взаимосвязях между модулями. Claude Code подходит для глубокого анализа кодовой базы, поиска ошибок и аккуратного рефакторинга. Главная задача — улучшить качество кода, не нарушив существующую функциональность.

**Мой вывод:** Для такой задачи я бы тоже рассмотрел Claude Code, поскольку здесь важнее понимание существующей архитектуры и безопасность изменений, чем скорость генерации нового кода.

## Кейс №2. Разработка бота с нуля за один вечер

**Задача:** Создать нового бота за один вечер: подготовить структуру проекта, написать код, подключить необходимые библиотеки и протестировать основные функции.

**Выбор эксперта:** Codex CLI.

**Обоснование:** Codex CLI подходит для быстрой генерации нового кода и последовательной разработки. Он позволяет оперативно создать структуру приложения, реализовать основные функции и проверить результат. Для небольшого MVP особенно важны скорость разработки и возможность быстро исправлять ошибки.

**Мой вывод:** Я бы выбрал Codex CLI для разработки первого прототипа, когда задача понятна, сроки ограничены и необходимо быстро получить работающее приложение.

## Кейс №3. Ежедневная работа с разными AI-моделями

**Задача:** Разработчик ежедневно выполняет разные задачи и хочет использовать GPT, Claude, Gemini, DeepSeek и другие модели без постоянной смены инструментов.

**Выбор эксперта:** OpenCode.

**Обоснование:** OpenCode позволяет подключать модели от разных провайдеров и переключаться между ними в единой среде разработки. Это удобно, когда для разных задач требуются разные возможности нейросетей. Также можно использовать бесплатные модели при наличии доступных лимитов.

**Мой вывод:** OpenCode подходит для гибкой работы с разными AI-моделями. Однако при выборе нужно учитывать фактическую доступность моделей, ограничения бесплатных тарифов и стоимость запросов. В предыдущем домашнем задании я столкнулся с ограничением бесплатного доступа OpenCode, поэтому для разработки VK-бота использовал Claude Code.
